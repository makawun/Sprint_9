# Sprint_9 — Автотесты для «Продуктового помощника»

UI-автотесты на Selenium для учебного сервиса
[«Продуктовый помощник»](https://foodgram-frontend-1.foodgram.education-services.ru/).

## Покрытые сценарии

- **Создание аккаунта** — регистрация и переход на страницу авторизации.
- **Авторизация** — вход и переход на главную страницу.
- **Создание рецепта** — заполнение формы, выбор ингредиента из списка,
  загрузка фото, проверка отображения рецепта.

## Стек

Python 3.12 · Selenium 4 · pytest · allure-pytest · Selenoid · Docker Compose · GitHub Actions
